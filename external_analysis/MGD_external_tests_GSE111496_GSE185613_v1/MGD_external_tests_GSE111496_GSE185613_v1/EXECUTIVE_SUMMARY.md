# Executive interpretation

## GSE111496
**Supportive, but narrowly.**
- Human HMGEC, 12 arrays, 2×2 DHT×LPS/LBP.
- Fixed 10-gene mouse panel mapped to 10 direct human symbols.
- Targeted module increased with LPS/LBP across both DHT strata.
- Restricted exact two-sided P = **0.015**.
- All 10 leave-one-gene-out versions retained a positive result; P range **0.005–0.045**.
- This supports **human MG epithelial inducibility**, not human MGD replication.
- The response is not a 10/10 same-direction gene effect; it is a module-level response dominated by several chemokines.

## GSE185613
**Negative boundary test.**
- HFD/circadian mouse dataset, 12 samples, 2 control + 2 HFD at each of three times.
- Fixed 10-gene panel: all measurable.
- Time-adjusted module effect = **-0.564**, exact two-sided P = **0.296**.
- Two of three time points were clearly negative; 15h was mildly positive.
- Leave-one-gene-out analyses did not rescue the result.
- This dataset should not be advertised as validation of the defense core.
- It is useful as evidence that the program is **recurrent but not universal**.

## Consequence for the manuscript
The emerging evidence is more defensible if framed as:
**a recurrent inflammatory-defense program across several genetic/environmental contexts, with context-specific failure or remodeling branches, rather than a universal fixed-gene signature present in every MGD model.**

GSE291177 remains the stronger external disease-context transfer result.
GSE111496 adds a human MG-epithelial inducibility layer.
GSE185613 should be retained as a negative boundary/sensitivity result, preferably in the Supplementary material.
The largest remaining increase in evidence level must come from the authors' own diabetic-mouse MG histology/IF experiment rather than adding more public datasets.
