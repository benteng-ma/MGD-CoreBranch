# Manuscript-ready Methods draft

### External human MG-epithelial perturbation analysis
GSE111496 was analyzed as an external human meibomian-gland epithelial perturbation dataset. The inflammatory-defense gene panel had been defined in the existing manuscript before this dataset was examined, although the external-transfer analysis itself was not prospectively registered. Analyses were restricted to the 12 immortalized human meibomian gland epithelial cell arrays in a 2×2 DHT-by-LPS/LBP design. The mouse panel was mapped to the direct human symbols CXCL5, CXCL1, CXCL2, CCL20, SLPI, S100A8, IFITM1, IFITM3, IL1RN and LCN2. Deposited cubic-spline-normalized intensities were log2 transformed. When more than one array probe mapped to a gene, the probe with the highest mean intensity across all 12 HMGEC arrays was selected independently of treatment effect. Gene-wise z scores were averaged within each array to obtain a sample-level module score. The primary LPS/LBP effect was the mean of the LPS-minus-vehicle differences within the DHT-naive and DHT-treated strata. An exact restricted permutation test enumerated all 400 label allocations obtained by permuting three LPS labels among six arrays separately within each DHT stratum. Leave-one-gene-out and maximum-variance probe-selection analyses were used as sensitivities; the DHT-by-LPS interaction was assessed only as secondary context.

### External HFD/circadian boundary analysis
GSE185613 was analyzed as a metabolic MG/eyelid boundary dataset. The uploaded processed matrix contained non-integer normalized expression values, and the GEO processing metadata state that FPKM normalization was used; accordingly, the matrix was not treated as raw counts. The fixed 10-gene mouse inflammatory-defense panel was log2(expression+1) transformed, standardized gene-wise across all 12 samples, and averaged to obtain a sample-level module score. HFD and control samples were represented by two samples at each of 9:00, 15:00 and 21:00. The primary treatment effect was estimated after adjustment for time-of-day and evaluated with an exact restricted permutation test that permuted two HFD labels among four samples within each time stratum, yielding 216 possible allocations. Leave-one-gene-out and percentile-rank module scores were examined as sensitivity analyses. Because GEO states that upper and lower eyelids were removed in whole for RNA extraction, this dataset was regarded as less MG-specific than purified-gland datasets.
