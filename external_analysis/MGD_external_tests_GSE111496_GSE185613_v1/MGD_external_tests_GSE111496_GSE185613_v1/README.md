# MGD external tests: GSE111496 and GSE185613

This package contains frozen external analyses for the MGD Core–Branch project.

Core rule:
- Do not change the pre-existing 10-gene inflammatory-defense panel because one external dataset is positive or negative.
- GSE111496 is a human MG epithelial perturbation/inducibility test.
- GSE185613 is a metabolic/circadian boundary test and is negative for the fixed panel.
- Neither dataset should replace the planned author-generated diabetic-mouse MG experiment.
