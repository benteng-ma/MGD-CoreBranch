## Suggested Methods text

### Independent cross-species transfer analysis in GSE291177
GSE291177 was added as an external rat meibomian-gland RNA-seq dataset after the original Core–Branch analyses had been completed. The inflammatory-defense gene panel itself had been defined in the existing manuscript before GSE291177 was examined; however, this external-transfer analysis was not prospectively registered. The deposited TPM matrix was used for module scoring rather than differential-expression inference because the supplied expression table contains normalized TPM values rather than raw integer counts.

The primary contrast was UVB-treated wild-type versus untreated wild-type libraries (3 versus 4 deposited RNA-seq libraries). The source article reports 6 WT eyes contributing to the UVB RNA-seq experiment, whereas GEO contains three UVB-WT libraries; because the deposited metadata do not explicitly document the eye-to-library pooling scheme, the present analysis treats the deposited RNA-seq library—not the eye—as the inferential unit. The pre-existing 10-gene Awat2 inflammatory-defense panel comprised Cxcl5, Cxcl1, Cxcl2, Ccl20, Slpi, S100a8, Ifitm1, Ifitm3, Il1rn, and Lcn2. Cxcl5 was not represented in the deposited rat TPM matrix, leaving nine measurable genes. TPM values were transformed as log2(TPM+1), standardized gene-wise across the seven wild-type libraries, and averaged within each library to obtain a sample-level defense score. The UVB-control score difference was evaluated by an exact permutation test enumerating all C(7,3)=35 possible allocations of three UVB labels; the two-sided P value was defined as the fraction of permutations with an absolute mean difference at least as large as observed. Sensitivity analyses used all 17 samples as the gene-wise standardization reference, a gene-wise percentile-rank score, and leave-one-gene-out re-estimation. P1.hMR samples were analyzed only as a secondary context analysis. PCA of the deposited TPM matrix was used for quality-control visualization and not for inferential testing.
